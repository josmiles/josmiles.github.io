The Problem

Registered dietitians in Kenya are expensive and rare. Most people have no access to personalised nutrition advice, leading to preventable diet-related illness.

The Solution

Full-stack nutrition coaching powered by LLMs. Users build a health profile, log food via chat or photo, and get personalised guidance across web, Android, and an admin dashboard.

Architecture

Next.js 14 on Vercel. Firebase Firestore (africa-south1) for food logs, chat history, streaks, and hydration data. Groq Llama 3.3 70B for AI chat; Llama 4 Scout 17B for food photo analysis. React Native + Expo SDK 52 via EAS cloud. Admin dashboard protected by Firebase JWT custom claims.

Impact
  • Three live platforms: web, Android, admin
  • Africa-South1 data residency
  • Real-time Firestore sync across platforms
Next Milestones
  • Nutritionix food database
  • Stripe Pro tier + iOS build

The Problem

Physical queues waste hours daily across Kenyan government offices, hospitals, and banks — with no visibility into position or wait time.

The Solution

Join queues remotely, get a numbered ticket, track position in real-time via WebSocket, receive SMS/WhatsApp alerts. Browser-first — no app install needed.

Architecture

Node.js 20 + Express on Render. WebSocket server for live queue state. PostgreSQL 15 across 10 core tables. Redis 7 caches queue positions. Africa's Talking + Twilio for notifications. EMA model learns from service times to predict wait dynamically.

Impact
  • Live API on Render, UI on Netlify
  • No app install required
  • AI wait-time adapts to real patterns
System Scope
  • Analytics: hourly stats + trends
  • Rate limiting, CORS, JWT auth

The Problem

Kenya's CBC curriculum restructured learning but affordable, curriculum-aligned digital tools remain scarce for most schools.

The Solution

A full LMS with an AI tutor that adapts to the student's grade. 30+ CBC topics, 6 subjects, 13 grade levels, and separate dashboards for all three user roles.

Architecture

React on Vercel. Node.js + Express REST API on Render. PostgreSQL with CBC-aligned schema. Groq AI responses calibrated per grade before each API call. Teacher dashboard for topic assignment and progress. Admin panel for full CRUD across users and topics.

Impact

  • AI adapts explanation per grade
  • Rated production-ready 8.5/10

The Problem

Elderly people carry irreplaceable life stories that disappear with them. Loneliness among the elderly is a global crisis. Existing tech is too complex and ignores voice interaction.

The Solution

"Ellie" — an AI companion for recording stories via voice or text, community feeds, memory timelines, and PDF memoir exports. Web and Android with full feature parity.

Architecture

React on Vercel (16 pages). Express on Render (12 routes). MongoDB for story + user data. Groq Whisper voice-to-text. Groq LLM for Ellie's AI. Cloudinary for photos. Stripe Pro subscriptions. Resend transactional email. 6-language localisation. 7-layer backend security. Android via Expo EAS. Built and deployed in one day — 10/10.

Impact
  • Perfect 10/10 score
  • Web + Android simultaneously
  • Voice, multilingual, payments all live
Key Features
  • Memory Timeline + "On This Day"
  • PDF memoir export
  • Community feed with reactions
