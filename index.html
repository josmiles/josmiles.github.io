The Problem

Registered dietitians in Kenya are expensive and rare. Most people have no access to personalised nutrition advice, leading to diet-related illness that is largely preventable. Generic apps don't adapt to local foods or individual health profiles.

The Solution

HealthAI is a full-stack nutrition coaching system powered by large language models. Users build a health profile (BMI, BMR, TDEE, macros), log food via chat or photo scan, and receive personalised guidance. Available on web, Android, and through a secured admin dashboard.

Architecture

Next.js 14 App Router frontend deployed on Vercel. Firebase Firestore (africa-south1) handles real-time data: food logs, chat history, weight tracking, streaks, and water intake across nested subcollections. Authentication via Firebase Auth. AI chat routed server-side through Groq's API (Llama 3.3 70B), with food photo analysis via Groq Vision (Llama 4 Scout 17B). React Native + Expo SDK 52 mobile app built via EAS cloud build. Admin dashboard protected by Firebase JWT custom claims.

Impact
  • Three platforms live simultaneously: web, Android, admin
  • Africa-South1 data residency — low-latency for Kenyan users
  • Real-time Firestore sync across web and mobile
  • Full streak, hydration, and calorie tracking in production
Next Milestones
  • Nutritionix API for accurate food DB
  • Stripe Pro subscription tier
  • iOS build via EAS cloud
  • Push notifications + weekly email reports

The Problem

Physical queues are a daily reality in Kenya — at government offices, hospitals, banks, and universities. People wait hours with no visibility into their position or estimated wait time, wasting productive time at scale.

The Solution

SmartQueue lets customers join queues remotely and receive a numbered ticket instantly. Real-time position tracking via WebSocket means no page refreshing. SMS/WhatsApp alerts notify when their turn approaches. Staff manage flow through a browser-based dashboard — no native app required.

Architecture

Node.js 20 + Express backend on Render handles REST API and a WebSocket server for live queue state. PostgreSQL 15 provides normalised persistent storage across 10 core tables. Redis 7 caches real-time queue positions for instant retrieval. Africa's Talking and Twilio provide an SMS/WhatsApp/email abstraction layer. An EMA (Exponential Moving Average) model learns from actual service times to predict wait times dynamically. Public display screens connect via WebSocket to show the NOW SERVING number at each counter.

Impact
  • Live API on Render, customer UI on Netlify
  • No app install required — browser-first for both sides
  • AI wait time model adapts to real service patterns
  • Display screen mode for public counters via WebSocket
System Scope
  • Analytics dashboard: hourly stats + wait-time trends
  • Multi-location support via UUID routing
  • Security hardening: rate limiting, CORS, JWT auth

The Problem

Kenya's 2017 CBC curriculum restructured how students learn — but affordable, curriculum-aligned digital tools remain scarce for most schools. Students lack on-demand academic support outside school hours.

The Solution

StMartin EDU is a full Learning Management System with an AI tutor that adapts responses to the student's grade level. Covering 30+ CBC topics across 6 subjects and 13 grade levels, it gives students, teachers, and admins separate dashboards with full CRUD control.

Architecture

React frontend deployed to Vercel. Node.js + Express REST API backend on Render. PostgreSQL database with CBC-aligned schema. Groq AI powers the learning assistant — responses are calibrated to the selected grade level before each API call. Teacher dashboard allows topic assignment and student progress tracking. Admin panel provides full CRUD across users, classes, and topics.

Impact
  • 13 grade levels fully supported (PP1–Grade 9)
  • AI adapts explanation complexity per grade
  • 3-role permission system: student / teacher / admin
  • Rated production-ready at 8.5/10
Roadmap
  • Security hardening to reach 10/10
  • Assessment and quiz module
  • Parent progress reports

The Problem

Elderly people carry irreplaceable life stories that disappear with them. Loneliness among the elderly is a global health crisis. Existing tech products are not built for this audience — too complex, too cold, and ignore voice as a primary interaction mode.

The Solution

GoldenEcho is an AI companionship and storytelling platform designed around simplicity and warmth. "Ellie" helps users record stories via voice or text, generates a community feed, preserves a memory timeline, and enables PDF memoir export. Available on web and Android with full feature parity.

Architecture

React frontend on Vercel (16 pages). Express.js backend on Render (12 routes). MongoDB for story and user data. Groq Whisper for voice-to-text transcription. Groq LLM for Ellie's conversational AI. Cloudinary for photo uploads. Stripe for Pro subscription payments. Resend for transactional email. 6-language localisation built in. 7-layer backend security. Android APK distributed via Expo EAS. 24/7 uptime monitoring via UptimeRobot. Built and deployed in one day — scored 10/10.

Impact
  • Perfect 10/10 score — full feature completion
  • Web + Android simultaneously shipped
  • Voice input, multilingual, payments — all live
  • 7-layer backend security, 24/7 monitoring
Key Features
  • Memory Timeline + "On This Day" feature
  • Community feed with hearts/reactions
  • PDF memoir export — life stories as a book
  • Stripe-powered Pro tier
