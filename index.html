The Problem

Registered dietitians in Kenya are expensive and rare. Most people have no access to personalised nutrition advice, leading to diet-related illness that is largely preventable.

The Solution

HealthAI is a full-stack nutrition coaching system. Users build a health profile, log food via chat or photo scan, and receive personalised guidance across web, Android, and an admin dashboard.

Architecture

Next.js 14 App Router on Vercel. Firebase Firestore (africa-south1). AI chat via Groq (Llama 3.3 70B); food photo analysis via Groq Vision. React Native + Expo SDK 52 mobile app. Admin dashboard with JWT custom claims.

Impact
  • Three platforms live: web, Android, admin
  • Africa-South1 data residency
  • Real-time Firestore sync across platforms
  • Full streak, hydration, calorie tracking live
Next Milestones
  • Nutritionix API for food database
  • Stripe Pro subscription tier
  • iOS build via EAS cloud

The Problem

Physical queues waste hours daily across Kenyan government offices, hospitals, banks — with no visibility into position or wait time.

The Solution

SmartQueue lets customers join remotely and get a numbered ticket instantly. WebSocket real-time tracking, SMS/WhatsApp alerts, staff dashboard — browser-first, no app install.

Architecture

Node.js 20 + Express on Render. WebSocket for live queue state. PostgreSQL 15 across 10 core tables. Redis 7 for real-time queue positions. Africa's Talking + Twilio for SMS/WhatsApp. EMA model predicts wait times dynamically.

Impact
  • Live API on Render, UI on Netlify
  • No app install required
  • AI wait time adapts to real patterns
  • Rate limiting, CORS, JWT auth
System Scope
  • Analytics: hourly stats + wait-time trends
  • Multi-location via UUID routing

The Problem

Kenya's 2017 CBC curriculum restructured learning but affordable, curriculum-aligned digital tools remain scarce. Students lack on-demand academic support outside school hours.

The Solution

A full LMS with an AI tutor that adapts to the student's grade level. 30+ CBC topics across 6 subjects and 13 grade levels. Separate dashboards for students, teachers, and admins.

Architecture

React frontend on Vercel. Node.js + Express REST API on Render. PostgreSQL with CBC-aligned schema. Groq AI tutor — responses calibrated to selected grade. Teacher dashboard for topic assignment and progress tracking.

Impact
  • 13 grade levels fully supported
  • AI adapts explanation per grade
  • 3-role permission system live
  • Rated production-ready at 8.5/10
Roadmap
  • Security hardening → 10/10
  • Assessment and quiz module
  • Parent progress reports

The Problem

Elderly people carry irreplaceable life stories that disappear with them. Loneliness among the elderly is a global crisis. Existing tech is too complex and ignores voice as a primary interaction mode.

The Solution

"Ellie" — an AI companion that helps users record stories via voice or text, generates a community feed, preserves a memory timeline, and exports PDF memoirs. Web and Android with full feature parity.

Architecture

React frontend on Vercel (16 pages). Express.js backend on Render (12 routes). MongoDB for story + user data. Groq Whisper for voice-to-text. Cloudinary for photos. Stripe for Pro subscriptions. 6-language localisation. Built and deployed in one day — scored 10/10.

Impact
  • Perfect 10/10 score
  • Web + Android simultaneously shipped
  • Voice, multilingual, payments all live
  • 7-layer security, 24/7 monitoring
Key Features
  • Memory Timeline + "On This Day"
  • Community feed with reactions
  • PDF memoir export
